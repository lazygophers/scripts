browse 扩展 UI 重设计 —— 三个方向

同一份内容（设置页 + 功能开关），shadcn 设计语言之内三种诠释。选定后统一落到 settings / panel / confirm 三个页面，并抽出公共组件层。

token 依据：shadcn 官方 theming 文档（ui.shadcn.com/docs/theming，类1）。zinc/stone/blue 具体色值按 Tailwind 阶梯换算，标 推测，实现时直接引官方 preset。

A · Zinc Dark —— shadcn 经典暗色

官方默认观感：暗底、白 primary、卡片堆叠。与扩展现在的暗色调最接近，改动心智最小。开关在左、域名在右。

B · Stone Light —— 暖浅色

暖灰浅底、卡片阴影、留白更足。macOS 亮色环境最舒服；radio 做成卡片式选择，气质最「产品」。

C · Neutral + 蓝 —— 双栏工具台

左侧锚点导航 + 粘底保存条 + 方法名 badge，密度最高。信息量大的设置页导航最顺手，蓝色 primary 提供强操作指引。
