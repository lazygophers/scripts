viewer 装好了

再做一步它才能显示你电脑里的文件。

文件访问权限

读取中…

  1. 地址栏输入 chrome://extensions 回车。
  2. 找到 viewer 这一项，点它的「详情」。
  3. 把「允许访问文件网址」那个开关打开。
  4. 回到本页刷新一下，上面那行会变成「已经打开」。

Firefox 没有这个开关，扩展默认就读得到本地文件，这一段可以不管。

主题

换主题连排版一起换：字体、字号、行距、每行多少字。选了立刻生效，已经开着的文件页也会跟着变。

自定义

以现成的一套为底子，只改你想改的。没改过的项跟着底子走。

安装说明

把本地的纯文本文件就地渲染成好看的样子。这段文字用的就是当前主题的字体、字号和行距。

引用看起来是这样，左边那道线用的是强调色。
// 注释是次要文字的颜色
export function isPlainTextPage(doc) {
  return doc.title === "";
}

提示框的色条用的是提示色。

强制拦截

有几类文件（例如 .yaml、.csv）浏览器会直接下载， viewer 没机会显示。打开这个开关，这类本地文件改为在 viewer 里打开；关掉就立刻回到下载。
