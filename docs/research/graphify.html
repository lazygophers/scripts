日常最常用的四条命令

graphify query "登录流程走哪几个文件"     # 问问题，图自己找答案
graphify explain "ArcheryClient"          # 大白话解释一个东西
graphify affected "check_build"           # 我改它会波及谁
graphify update .                          # 代码变了，刷新图（不要 LLM，免费）

MCP tools（AI 直接调的 11 个）

tool干嘛的
query_graph按问题搜图，返回相关节点和边（默认 2000 token 预算）
get_node取一个节点的完整信息
get_neighbors取一个节点的全部直接邻居
get_community取某个「子系统」的全部节点
god_nodes连接数最多的节点 = 架构枢纽
graph_stats节点数、边数、社区数、confidence 分布
shortest_path两个概念之间最短路径
list_prs / get_pr_impact / triage_prsPR 看板 + 每个 PR 的图影响面 + review 优先级排序
每个 tool 都自动注入一个可选的 project_path，所以一个 server 能服务多个项目。 出处 graphify/serve.py:1693-1845、serve.py:1827-1845

能力边界

能
  • 37 种代码语言，跨文件 calls/imports/inherits 边
  • .mcp.json、go.mod、pyproject.toml 等包清单
  • Markdown / PDF / Office / 图片 / 音视频 / YouTube
  • 活的 PostgreSQL schema（--postgres DSN）
不能 / 要注意
  • PostgreSQL 列级细节不进图（只有表、视图、函数、外键）
  • OCaml / Terraform / Robot 等要装 extra，不装解析不了
  • Google Drive 的 .gdoc 只是指针，要装并登录 gws CLI
  • 代码以外的一切都要走 LLM API（README.md:370）

几个值得知道的细节

为什么有一堆日期目录

每次覆盖 graph.json 前的完整备份，不是增量归档。
只在两种情况触发：这张图花过真 LLM token，或者社区名被人改过。
GRAPHIFY_NO_BACKUP=1 可关。
出处 graphify/export.py:24-70

为什么语义缓存不按版本分目录

AST 缓存按 v0.9.57-s2 分（重算免费）；
语义缓存故意不分版本——重抽要花 LLM 的钱。
只按 prompt 指纹分 p<fingerprint>/。
出处 graphify/cache.py:930-960

.sig 文件干嘛用

图重新聚类后，同一个社区编号可能已经指向完全不同一批节点，旧的 LLM 名字就错了。
签名逐个社区比对，变了的先用当前枢纽名顶上，并提示你跑 graphify label。
出处 graphify/cli.py:2170-2190

目录名可以改

环境变量 GRAPHIFY_OUT，接受相对名（graphify-out-feature）或绝对路径（/shared/graphify-out）。
给 worktree 或多人共享输出用。
出处 graphify/paths.py:26

三、有哪些产出物

常驻 每次构建都写，应该提交 git

graph.json · graph.html · GRAPH_REPORT.md · manifest.json · .graphify_analysis.json · .graphify_labels.json + .sig · .graphify_root · .graphify_semantic_marker
设计上就是给团队共享的：别人 clone 下来就有一张地图，不必自己重建。manifest.json 存相对路径，所以可移植。出处 README.md:432、README.md:439

按需 跑对应命令才有

类别产出物

本地专属 建议 gitignore

cost.json（LLM 花费记录，README 点名要 ignore）· cache/（README 说可选：提交换速度，不提交保持仓库小）

仓库外 写到别处的东西

~/.graphify/global-graph.json跨仓库全局图
~/.graphify/repos/<owner>/<repo>/graphify clone 的落点
~/.cache/graphify-queries.log查询日志，默认关闭，要显式 GRAPHIFY_QUERY_LOG_ENABLE=1 才写
各平台配置CLAUDE.md 段落 + hook、.cursor/rules/graphify.mdc、AGENTS.md、GEMINI.md 等
git hookspost-commit / post-checkout + 一个 graph.json 的 union merge driver（让它永远不出冲突标记）
