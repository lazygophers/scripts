# email

多邮箱收发（QQ/Gmail/163/126/iCloud/Fastmail/Zoho，按邮箱分别登录）

## 用法

用法：`email COMMAND`

**命令**

| 命令 | 说明 |
| :--- | :--- |
| `attach` | 把一封邮件的附件下载下来。 |
| `check` | 对已配置的邮箱重新验证一次连接（换过授权码、怀疑过期时用）。 |
| `inbox` | 列最近的邮件（最新在前），不会把邮件标成已读。 |
| `list` | 列出已配置的邮箱。 |
| `login` | 配置一个邮箱：选服务商 → 照引导拿授权码 → 真连一次验证 → 通过才保存。 |
| `mark` | 标已读；加 --unread 标回未读。 |
| `read` | 读一封邮件的正文。 |
| `remove` | 删掉一个邮箱的配置。 |
| `search` | 全文搜索（正文和头都搜）。 |
| `send` | 发一封邮件，可带附件。 |
| `use` | 把某个邮箱设为默认（不加 --email 时就用它）。 |

## 示例

```bash
email inbox
```
