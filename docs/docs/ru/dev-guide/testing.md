# Тестирование

```bash
python3 -m unittest discover -s tests -q
```

Набор тестов лежит в `tests/` в корне. Новые команды должны получать unit-тесты: логика тестируется в `lib/{имя}.py`; обёртки только пробрасывают вызов. `tests/test_lazyhelp.py` сверяет bin/ с реестром `TOOLS` — не забудьте зарегистрировать новые входы.
