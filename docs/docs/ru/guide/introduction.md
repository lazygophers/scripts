# Введение

`scripts` — набор инструментов эффективности: быстрые скрипты для типовых задач разработки и эксплуатации. В `bin/` только тонкие обёртки, реализации — в `lib/cli/`, общие возможности — в `lib/`.

## Особенности

- **Тонкие обёртки**: каждый скрипт в `bin/` — одна и та же обёртка (правка path + `from lib.cli.<модуль> import main`), без бизнес-логики и без symlink'ов; реализация — `lib/cli/<имя>.py`, общие возможности — плоские модули `lib/`.
- **Запуск без установки**: все команды объявлены в `[project.scripts]`, поэтому `uvx git+https://github.com/lazygophers/scripts` работает без клонирования.
- **Классификация по назначению**: Git-процессы / Git-сотрудничество / Сборка и проверки / Данные и сеть / Веб-поиск / Процессы и запуск / Файлы и система — одна страница через `lazyhelp`.
- **Пакетные операции**: `merge_*` / `push_*` / `switch_branch` / `sync_master` — один репо и пакет по нескольким.
- **Безопасность прежде всего**: самоисключение в управлении процессами, проверка чистоты рабочего дерева и откат перед Git-операциями.

## Быстрый старт

Запустить один раз, ничего не устанавливая:

```bash
uvx git+https://github.com/lazygophers/scripts                     # список всех инструментов
uvx --from git+https://github.com/lazygophers/scripts checkwork    # запустить один
```

Оставить на этой машине:

```bash
./bin/inject            # внедряет клонированный bin/ в PATH оболочки
```

Перезапустите оболочку, затем вызывайте `checkwork` / `merge_canary` / ... из любого каталога.

См. [Скрипты](./scripts.md) и репозиторий GitHub [lazygophers/scripts](https://github.com/lazygophers/scripts).
